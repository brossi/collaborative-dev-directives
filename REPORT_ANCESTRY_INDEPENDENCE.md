# Experiment 5: Ancestry Independence Test for Walker Noise Floor Regression

## Objective

Experiment 4 established an Edge Jaccard regression for predicting Walker noise floors between topology pairs:

```
noise_floor ≈ 1.243 × jaccard - 0.721    (R² = 0.572, N = 10 pairs)
```

All 10 training pairs came from variants derived from the same parent grid (Open). This experiment tests whether that relationship is a genuine structural property or an artifact of shared derivation history by introducing 5 independently generated topologies that share **zero ancestry** with Open or each other.

## Design Constraint

**No variant is generated by modifying Open's edge set.** Every independent variant is constructed from first principles on the same 100-room 10×10 positional grid. Rooms occupy identical (row, col) positions. Only the connections are independently generated. This is the inverse of Experiment 4's constraint — there, all variants shared ancestry; here, none do.

## Independent Variants

| Variant | Method | Edges | Avg Degree | Jaccard w/ Open |
|---------|--------|-------|------------|-----------------|
| F (Prob. Cardinal) | Each cardinal edge included at p=0.80 (seed 700), connectivity repaired | 344 | 3.44 | 0.920 |
| G (Radius-2 Geom.) | All Manhattan dist ≤ 2 pairs, trimmed to avg degree ~4.0 (seed 701) | 400 | 4.00 | 0.248 |
| H (Span+Rewire) | Wilson's algorithm spanning tree (seed 702) + 150 random edges (seed 703) | 498 | 4.98 | 0.019 |
| I (Watts-Strogatz) | Ring K=3, β=0.25 rewiring (seed 704) | 600 | 6.00 | 0.125 |
| J (Config. Model) | Open's degree sequence, randomly wired (seed 705) | 366 | 3.66 | 0.025 |

Variant F achieves high Jaccard with Open (~0.92) through structural coincidence — both are dense cardinal grids — but was not derived from Open. Variants H, I, J have near-zero Jaccard with Open, confirming truly independent construction.

## Results

### Phase 1: Independent-vs-Open Pairs (5 pairs)

| Pair | Jaccard | Noise Floor | Exp4 Predicted | Residual |
|------|---------|-------------|----------------|----------|
| A-F | 0.920 | -0.066 | +0.423 | +0.489 |
| A-G | 0.248 | -0.093 | -0.412 | -0.319 |
| A-H | 0.019 | +0.118 | -0.698 | -0.815 |
| A-I | 0.125 | +0.161 | -0.566 | -0.727 |
| A-J | 0.025 | +0.090 | -0.690 | -0.780 |

The Exp4 regression predicts **wildly incorrect** values for independent pairs. The A-F pair is the most revealing: despite a Jaccard of 0.92 (the highest in the entire dataset), it has a noise floor of -0.066 — nowhere near the +0.42 the regression predicts. Structural coincidence in edge overlap does not produce the same noise floor as structural derivation.

### Phase 2: Independent-vs-Independent Pairs (10 pairs)

| Pair | Jaccard | Noise Floor |
|------|---------|-------------|
| F-G | 0.240 | +0.150 |
| F-H | 0.019 | +0.108 |
| F-I | 0.116 | -0.047 |
| F-J | 0.026 | -0.218 |
| G-H | 0.011 | -0.086 |
| G-I | 0.094 | +0.055 |
| G-J | 0.032 | -0.046 |
| H-I | 0.020 | +0.165 |
| H-J | 0.021 | -0.162 |
| I-J | 0.015 | +0.172 |

These 10 pairs share zero ancestry with Open AND zero ancestry with each other. Noise floors cluster near zero (mean = +0.003) with no discernible relationship to Jaccard.

### Phase 3: Regression Comparison

| Metric | Original (N=10) | Pooled (N=25) |
|--------|-----------------|---------------|
| R² | 0.572 | 0.047 |
| Slope | 1.243 | 0.132 |
| Intercept | -0.721 | -0.012 |
| RMSE | 0.170 | 0.187 |
| p-value (slope) | 0.011 | 0.300 |

**R² collapsed from 0.572 to 0.047** — a 92% reduction. The slope collapsed from 1.243 to 0.132 and is no longer statistically significant (p = 0.30).

### Statistical Tests

**Test 1 — Systematic Bias:** Mean residual for independent pairs = +0.580 (t = 6.71, **p < 0.0001**). The Exp4 regression systematically underpredicts noise floors for independent pairs because independent topologies cluster near noise_floor ≈ 0 regardless of Jaccard, while the regression predicts strongly negative values for low Jaccard.

**Test 2 — Variance Inflation:** Variance ratio = 3.49× but Levene's test p = 0.50 (not significant). The spread of residuals is larger for independent pairs but not beyond what sampling variability could explain at this sample size.

**Test 3 — R² Collapse:** R² dropped from 0.572 to 0.047, well below the 0.40 threshold. Ancestry was inflating the original fit.

**Test 4 — Ancestry Interaction:** No significant interaction terms (all p > 0.50). This is because once independent pairs are added, the Jaccard → noise floor relationship disappears entirely — there's nothing for ancestry to modulate.

### Phase 4: Prediction Error Distribution

Mean absolute prediction error:
- Training pairs (Exp4): 0.130
- Independent pairs: 0.621

Independent pairs have **4.8× larger** prediction errors. The distributions do not overlap — the smallest independent-pair error exceeds most training-pair errors.

## Conclusion: Regression Does Not Generalize

**The Edge Jaccard regression is an artifact of shared ancestry, not a general structural property.**

The key evidence:
1. **R² collapse:** 0.572 → 0.047 when adding independent pairs
2. **Systematic bias:** The regression is off by +0.58 on average for independent pairs (p < 0.0001)
3. **The A-F smoking gun:** Two dense cardinal grids with Jaccard = 0.92 but noise floor = -0.07. If Edge Jaccard truly predicted noise floor, this pair should have the highest noise floor in the dataset. It doesn't. Coincidental edge overlap ≠ behavioral similarity.

### Why Does Ancestry Create the Illusion of Predictability?

When all variants are derived from Open (by pruning, rerouting, or reorganizing its edges), the variants share more than just edges — they share the **spatial correlation structure** that comes from being modifications of the same parent. Two pruned variants of the same grid produce correlated random walks not because they share edges, but because their edges were drawn from the same structural template. Edge Jaccard happens to correlate with "degree of derivation" within this family, creating a spurious regression.

Independent topologies break this because they can match Open's Jaccard without matching its spatial correlation structure (Variant F) or fail to match Jaccard while still producing similar noise floors (Variants H, I, J all have near-zero Jaccard but varied noise floors).

### Practical Implication

**Walker calibration (~1,010 sessions per variant) cannot be bypassed for independently generated topologies.** The Edge Jaccard shortcut is valid only within a topology family (variants derived from the same parent map via pruning/rerouting). For any topology generated from scratch — which is the normal case in game development — full Walker calibration remains mandatory.

The Exp4 regression remains useful in one narrow scenario: when a designer is iterating on an existing map by adding/removing walls, and wants to estimate how much the noise floor changed. For that use case, ancestry is guaranteed, and the regression provides a useful fast estimate.
