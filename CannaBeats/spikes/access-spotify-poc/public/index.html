        What this proves

        • Only a server-issued invitation can create an account.
        • Only a registered passkey can restore an authenticated session.
        • Only a host-role account can pass the protected host check.
        • A desktop installation needs explicit passkey approval and remains independently revocable.
        • A game code locates a lobby but never replaces account authentication.
        • Spotify refresh credentials remain in this browser profile.
